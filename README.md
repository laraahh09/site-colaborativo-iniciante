# site-colaborativo-iniciante

1. alteração dentro da minha branch
2. comenta > commit
3. push
4. no git, faça o pull request manual
5. merge
6. no terminal do vs code, dê o comando git checkout main
7. entrou no main, dê os comandos: git pull origin main > git push origin main
8. volte para a sua branch, com o comando: git checkout nomedabranch
9. na branch, dê o comando git pull origin main
